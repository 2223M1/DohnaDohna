# 人物口吻、命名与改编

只在这些内容影响本次交付时读取。

## 创作前的内部证据简报

明确原作阶段、参与人物、彼此关系、掌握的信息、即时目标和本次冲突。把原作重述、原作兼容的空隙补全、明确的模组原创分支分开；没有证据就不虚构过去或既定结局。

人物口吻来自能定位到说话人和情境的原作场景。区分叙述、直接对白、内心、UI 标签、译文习惯和临时情绪。重大人物概括尽可能用不同场景互证，不把一声伤害叫喊、一个口头禅或一段字节码注释推广为人物全部性格。

角色用途表只说明某录音可在什么用途下播放。引用名中的日语片段不自动成为完整转写，中文消息也不自动对应同编号 OGG。

## 命名

读当前 `Docs/card-catalog.md`、相关三语文本及既有模型 ID。结合已批准的机制寻找原作名词、已证实短语或意象；不堆日本式词汇、忍者杀手专用格式或泛化动漫台词。

区分 `原作名词`、`有据压缩`、`原创拟名`。名称应表达机制而非冒充原作出现过的术语；显示名修改不自动授权更改存档 ID、注册 ID 或资源路径。

## 事件与风味

让触发、人物目标、玩家选择和后果形成因果链。原作素材提供事实与主题，不自动确定卡牌平衡、费用、数值或模组新结局。UI 文案不能掩盖实际代价和结算效果。

写作后检查人物知识与关系阶段、原作与原创的归属、三语术语一致性，以及是否把译文口癖机械扩散到所有人物。只保留对本次任务真正有用的短证据，完整原作文字留在私人资料包。
