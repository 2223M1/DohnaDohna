# 人物口吻、命名与改编

仅在人物、名称或叙事影响交付时使用。

## 人物与场景

先核对故事阶段、人物关系、已知信息和即时目标，区分原作重述、兼容原作的补全与模组原创分支。没有证据不虚构既定经历或结局。

口吻取自能定位说话人和情境的场景；区分叙述、对白、内心、UI 标签、译文习惯和临时情绪。重大人物概括尽量跨场景互证，不能将受伤叫喊或单个口头禅推广为全部性格。语音用途与转写限制见 [source-map.md](source-map.md)。

## 命名与设计

读当前 `Docs/card-catalog.md`、相关三语和模型 ID，结合已确定的机制选择原作术语、短语或意象，标明 `原作名词`、`有据压缩` 或 `原创拟名`。显示名变化不自动改存档 ID、注册 ID 或资源路径。

让触发、人物目标、玩家选择和后果相互对应；文案应说明真实代价和效果。原作主题不自动决定模组数值或新结局。

交付前核对人物知识、关系阶段、原作/原创归属与三语术语；不把同一译文口癖套给所有人物。仅保留支撑本次创作的短证据。
