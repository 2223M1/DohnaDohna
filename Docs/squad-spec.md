# DohnaDohna 小队运行规格

现行规则：2026-10-09 小队卡池、真实初始遗物、先古升级。覆盖旧版25血、死牌封存和开场轮换；历史报告仅为当时证据。

## 身份、队列与恢复

一个真实Player，共享手牌、能量、遗物、药水、奖励；四个原生归属友军实体独立持有血量、格挡、能力。十人任选四人，无解锁门槛。先选中网关角色，再按原生确认进入二级原生按钮栏；可取消、排序，返回一级清空草稿。队列从左后排至右前排。

敌方主动AttackCommand每段在命中特效之前选择当前前排，群攻只命中小队一次，死亡无溢出。明确指定成员的荆棘反伤、自伤、毒保持归属；指向隐藏宿主才解析为前排。原生能力、保命、数字、火花、HitVfx/HitSfx与死亡流程不被另写的结算替换。荆棘不额外播放身体受击与受击配音。四人全灭才原生失败。

公共牌由当前前排执行；专属非近战牌由归属者执行；专属近战牌提交后先插至前排，其余人顺移，再更新光环和换位收益并执行卡牌。取消选择不移动。直接换位卡仍为两人对调。队列与HP在战后保存，跨战斗和读档保持。

火堆通过原生选择卡面板选择一名死者，以0血参与该次原生休息治疗，同时治疗其他生者，复活者进入队尾。先古之民先让全部死者以0血接受原生全队恢复与进阶修正，再进入后排。不硬塞1血或固定复活量。只保存小队边界状态，不建立额外战斗存档或卡牌封存。

缩小甲虫能力属于中招者；大蘑菇放大获得上限者。共享上限变化沿现有四人分摊，不复活死者。体型仅改变身体和影子，不改变槽位或HUD；死亡仍可重排。保留原生倍率与能力解除规则。

光环实时增减自身贡献、不叠加；来源死亡立即撤回。虎太郎按已查证的原生正面增益白名单计种类，回合初已有正值也计入，消失不收回奖励，不统计自身派生力量。安缇娜多段对同一敌人只计一次，被格挡也计。爱丽丝并入每段伤害，不追加新伤害段。

梅蒂可全战只触发一次：直接交换治疗另一方；她插队治疗原前排；别人越过她治疗移动者。小丑每次完整重排最多触发一次；死亡、首次布阵、跨战斗恢复不触发这两人的换位收益。

奥罗巴斯之触通过原生网格选择四件中的一件升级，沿原生Replace和存档ID。升级只将收益数值翻倍，不将“首次”改为两次；绮菈绮菈选择2张。旧SquadStandard不再新发，只有读到真实旧标记且未熔化、无新角色遗物时迁移一次，绝不因遗物缺失自动补发。取消旧加能、抽牌及自动轮换。

## 基础牌、卡池与代打

初始10张：四打击、四防御、一换位、一协同攻击。

- 打击1费6→9；防御1费5→8；换位0费，升级获得保留，原生指针选择队员直接对调。

170种可获得牌=20公共普通牌＋每人9罕见6稀有。每局常规池80种（所选成员死亡仍保留），原型全局不重复，具体清单以Content/card-pool.json及编辑板为准。模型为独立Mod卡，保留0.111.0原名、原图、主要规则、费用、数值、升级及关键词；双宿主使用同一基线。旧测试代表牌保留存档ID但退出奖励。

死亡／缺席专属牌不再封存或禁用：由前排代打，攻击1费6→9并抽1；技能1费5→8挡并抽1；能力1费抽2→3并按原生能力牌流程离开牌堆。保留关键词、外部费用修正，不执行原正文、专有出牌限制或额外触发；费用、目标、描述同步临时变化，不改永久牌。生成、复制、自动打出及重放一致，归属者恢复后恢复原正文。

“1费”是原生改费流程的基础输入，不锁定最终费用。蛇眼的原生混乱抽牌改费、子弹时间的本回合免费，以及后续加减费仍按原生 LocalCostModifier 的施加顺序和期限处理。原X费牌代打时按普通1费参与该流程；复制保留原始X身份，角色恢复时自然还原。不追加一个会覆盖已有改费的临时费用副本。

斩杀收益遵循原生命令：最后一敌人的狂宴上限、贪婪之手金币、狩猎额外奖励正常保留；击倒在非清场击杀时回能，清场后 PlayerCmd.GainEnergy 按宿主 IsEnding 规则不再回能，不为它另造战后能量结算。

个人属性、防护、行动增益留在本人；纯共享资源、牌堆、持续场地能力挂真实玩家，来源死后仍沿原生期限。已施加给他人的状态不随来源死亡删除。共享Power用原生状态栏显示并提示来源，不显示第五人。真实角色决定本人攻击、减益、协同与格挡交接；共享抽弃、能量不按四人重复。

## 常驻飞碟与充能球

安缇娜飞碟从现有装备层分离，平时悬停于头顶偏后；攻击时独立飞至真实目标附近，完成发射再返回。本人、队列、血条不随飞碟移动。飞碟、射口、充能光与光束共用刚性变换，原作特殊动作的双飞碟构图保留；充能球跟随主飞碟上方。飞抵后停稳再发射，已发出光束不被返航拖走；连续攻击从当前飞行位置衔接。复用真实玩家唯一的原生OrbQueue、球模型、激发、生成、声音和提示，存活安缇娜开战提供3空槽。

原生大小球槽在飞碟上方弧形排列；扩容沿原生上限。集中取安缇娜，冰霜每次保护当前前排，等离子进入共享能量。安缇娜真正死亡清空现有球且不激发，飞碟退场，个人自动触发停用；球槽容量不因换位重置。没有存活安缇娜开战不赠3槽，外来卡／药水生成的球保持原生通用行为，在前排附近显示，不复原旧球。

卡框、标题横幅、插画边框按角色色着色，不染人物与文字；公共蓝灰#657F9A。仍用一个逻辑卡池和CardAssetProfile，稀有度纹理保留。

## 资源边界

基础打击素材仍来自默认攻击优先、单正伤害节点的已批准动作。2026-10-08 用户授权重新剪辑普通攻击、处决和普通受击：可重组姿态、移动可见命中时点、调整视觉位移，但不改变卡牌数值或增加结算次数，打击仍1费、单次6→9伤害。原始导入时间线保留作为素材依据，运行时使用角色自己的剪辑。

| 基础打击动作 | 队员 | 原作依据 / 暂用原因 |
| --- | --- | --- |
| 攻击１ | 阿熊、爱丽丝、虎太郎、菊千代、小丑、扎帕、绮菈绮菈 | 默认动作，单正伤害节点 |
| 攻击２ | 安缇娜、梅蒂可 | 默认攻击１分别有6、4个正伤害节点；暂用单节点伤害技能 |
| 攻击３ | 珀尔诺 | 默认攻击１有2个正伤害节点；攻击３初始可用，且比攻击２短 |

依据外置当前原作表`30_技能数据.x`的`motionKey/level/type`与`33_モーション情報.x`的`Damage.Enable/Percent`。伤害技能与增益/治疗技能分别判定，不把名称含“攻击”的辅助动作当作普攻。以上是模组暂定适配，不改变专属攻击配置；后续细调另行确认。

`tools/Import-OriginalRoles.py` 只解析当前动作表及其明确引用，校验素材来源散列。
`tools/Prepare-Fmod.py` 新建本项目 Studio 工程，只保留宿主 Master/mixer关系，不引入历史自定义事件或bank。
`tools/Generate-Content.py` 仅生成选定原图的占位肖像；`tools/Sync-CatalogText.mjs` 同步三语，`Docs/card-metadata.json` 是实际宿主运行时导出。
原作图片、角色时间线、音频输入留在忽略提交的本地生成/制作目录，运行包仅包含选定资源和自己的bank。

所有通过 `SquadAudio` 播放的本模组音效与配音统一衰减20 dB，线性音量0.1；不修改原生音乐、环境音或音量设置。短版攻击不播放人物语音（含处决），动作音随保留节点播放并在动作收尾/替换时释放。受击配音来自原作表11“伤害”分类，死亡配音来自“伤害死亡”；同一角色新的受击/死亡语音替换上一段反应语音。

保留可见起手、枪口/飞碟/光束、挥击等有辨识度的素材，删去长跑动、弹丸漫游和大幅往返。普通与处决均由原生 AttackCommand 在真实目标上生成一次配套命中图声；群攻每目标一份视觉、整次一个命中声，数字、破盾与基础反馈按原生规则。本版选择不保留处决的原作命中爆炸与混合命中音，以配合短时序，避免双重反馈。

怪物身体只播放原生受击，不叠加普通攻击的多娜多娜目标位移、震动、闪色或身体控制；普通攻击不触发特写镜头、隐藏其他角色或目标参数、黑幕/背景变色、全屏闪色与线条。角色身体受击替换不取消敌方原生 HitVfx、HitSfx、自定义命中特效、伤害火花、数字和破盾声音，不手动补播这些反馈。

游戏内模组设置 → DohnaDohna → 演出提供“女性角色特殊死亡演出”，默认关闭。关闭时所有队员仅播放各自原作倒下动作和死亡语音，不创建海报；开启时六名女性再并行播放原作海报并等待收尾，男性不变。使用 RitsuLib 全局本地设置（presentation.json），不进入跑局存档、不影响血量、真正死亡判定、代打或接替顺序；每次死亡入口读取一次，更改从下一次死亡起生效。主菜单和跑局暂停菜单沿框架现有设置入口访问。

战斗外事件损血死亡也遵循同一海报开关；没有战斗身体节点时不另造倒下实体。死亡语音由 RitsuLib 原生房间生命周期持有并在换房时释放，不因关闭海报而同步截断，不为语音额外阻塞原生损血结算。

动作内局部身体/装备整体作短步或原地化处理；同组图层不逐图插值到敌人。安缇娜阵列飞碟、充能光和光束保留共同目标构图，已发出的特效固定在场景坐标。处决也不再改写敌人身体轨迹，敌人使用自己的原生受击/死亡。取消、替换与退出只释放本次演出所有的节点、声音与变换。

身体与原生血条采用共同横向站位原点，`groundContact.X=0`；不按最低一只脚或整张人物包围盒重新居中。首帧脚底高度仅用于固定的垂直接地适配。原作图层偏移、非对称姿态、待机踏步保持原样，不逐帧锁脚；血条/状态栏不随身体姿态移动。

地面影子采用 STS2 原生风格的低矮黑色毛边笔触，而非可辨认的人形剪影。逐帧 IsShadow 身体层控制形态，离线生成；场景原生深度、身体之前绘制，跳跃时留在地面并缩小。身体/装备/发射特效保留原作内部层级排序，不把原作 Z 数值直接映射成 Godot 全画布 Z；已发射特效继续持有场景变换，不追随之后的人物动作。
攻击临时升层只作用于 `OriginalMotion` 身体/特效节点；影子保持在原生 AllyContainer 的地面绘制顺序（EnemyContainer 之前），不能随攻击升到敌人上方。替换/取消/退出恢复本次身体层级，不改影子、HUD或外部变换。

只有可靠预判这一次攻击能清除全部剩余主要敌人时启用处决特写（2026-10-07确认），不是击杀任意敌人。单次原生伤害查询考虑真实行动者、力量/活力、格挡、无视格挡、减伤、缓冲、替伤及保命/阻止战斗结束规则；不执行命令或消费能力。改变攻击段数、存在目标反伤或未知外部模型参与的情况保守不触发，不为演出冻结HP、推迟原生死亡或替代随机/召唤算法。

处决使用受场景边界约束的短特写，目标倍率1.16，按主体取景进一步限制；同屏背景、身体、血条/状态、意图与原生命中特效共同变化，不移动真实布局与交互根节点。配合短压暗背景和旁人/HUD淡出，结束、取消、退出恢复。原作长镜头、怪物击退/震动控制、全屏线条等不再进入短版攻击。

攻击剪辑的初始可见命中门槛通常为0.15秒；安缇娜为容纳飞碟飞抵目标取0.25秒。快速模式减半，即时模式不等待；已在收势时的新动作可从兼容姿态续接。逻辑命中及原生附加效果始终 await，纯视觉收势由角色 `_Process` 持有，不阻挡下一张牌，各角色不互等。单次自然收势，不设置等连击的停顿；旧尾段不能复位新动作。处决使用稍可读的起手和短收势，不沿用原作数秒全片。爱丽丝狙击删除长后空翻，其他角色原地或短步完成；这是本轮授权覆盖旧“原作距离不可压缩”要求。

普通受击保留短失衡姿态，删除图层整体击退和素材后半段的跳回/落地，约0.25秒恢复待机。它是独立非阻塞视觉，荆棘反杀最后敌人后仍能收尾；新受击、真正死亡或退出替换/清理。保留严格300ms受击语音重播门槛及死亡覆盖。视觉中断不会补打一击或改变反伤顺序。
