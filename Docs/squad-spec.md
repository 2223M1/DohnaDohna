# DohnaDohna 小队运行规格

现行规则：2026-10-09 小队卡池、真实初始遗物、先古升级。覆盖旧版25血、死牌封存和开场轮换；历史报告仅为当时证据。

## 显示术语（2026-10-11）

- 最前方同伴：小队队首，负责通常的敌方攻击承伤、公共牌和代打。
- 正前方同伴：紧邻当前角色前面的一名同伴，不等于固定队首。
- 相邻同伴：队列中紧邻角色的前／后一位；具体数量与方向仍由效果规定，不新增作用范围。
- 普通成员称呼统一为“同伴”；“后方同伴”仍表示角色后面的同伴，不擅自缩为紧邻后一人。移动目的地仍称“最前方”，复活位置称“队尾”。

采用已查证的原作中文“同伴／相邻”并作明确化组合，不宣称三个完整词组均为原作逐字术语。英语区分frontmost member与member directly in front；日语区分先頭の隊員与すぐ前の隊員。内部模型、存档ID及规则不变。充能球“最右侧”不是队列术语，不替换。

## 身份、队列与恢复

一个真实Player，共享手牌、能量、遗物、药水、奖励；四个原生归属友军实体独立持有血量、格挡、能力。十人任选四人，无解锁门槛。先选中网关角色，再按原生确认进入二级原生按钮栏；可取消、排序，返回一级清空草稿。队列从左后排至右前排。

选人海报（2026-10-11）：一级按原作SceneTitle的1280×720画布、人物原位/原尺寸、入场/视差/圆环处理，按画布裁切而非把整幅人物包围盒缩进安全区。二级隐藏首页人物，改用所选同伴的高清战斗服立绘半身组合；四列与队列从左到右一一对应，角色专属色底板、底部淡出，选取/取消/重排即时同步，返回一级清空。原生按钮、说明组件、卡牌预览和确认入口不变。裁切工具为`tools/Prepare-SelectArt.py`，商业原图与生成物不入公开源码。

四人作为开战初始参与者建立，不等开场遗物结算后再召唤。能力施加与叠层查找使用同一个真实接收者；个人能力不随换位迁移，共享能力显示在队伍上方的原生能力栏。控制台godmode覆盖存活同伴，开关与下一战订阅仍由原版管理。身份与可选模组边界见[原生归属说明](squad-native-ownership.md)。

原生空牌堆等共享提示由气泡生成时的当前存活前排说出，使用该同伴原生TalkPosition；指定同伴/敌人的对话不改归属。换位不切换Player身份。虎太郎被动与协同攻击各持有独立来源的原生临时力量，避免嵌套施加中断原生弃牌流程；数值与回合期限不变。

敌方主动AttackCommand每段在命中特效之前选择当前前排，群攻只命中小队一次，死亡无溢出。明确指定成员的荆棘反伤、自伤、毒保持归属；指向隐藏宿主才解析为前排。原生能力、保命、数字、火花、HitVfx/HitSfx与死亡流程不被另写的结算替换。荆棘不额外播放身体受击与受击配音。四人全灭才原生失败。

公共牌由当前前排执行；专属非近战牌由归属者执行；专属近战牌提交后先插至前排，其余人顺移，再更新光环和换位收益并执行卡牌。取消选择不移动。直接换位卡仍为两人对调。队列与HP在战后保存，跨战斗和读档保持。

火堆通过原生选择卡面板选择一名死者，以0血参与该次原生休息治疗，同时治疗其他生者，复活者进入队尾。先古之民先让全部死者以0血接受原生全队恢复与进阶修正，再进入后排。不硬塞1血或固定复活量。只保存小队边界状态，不建立额外战斗存档或卡牌封存。

缩小甲虫能力属于中招者；大蘑菇放大获得上限者。共享上限变化沿现有四人分摊，不复活死者。体型仅改变身体和影子，不改变槽位或HUD；死亡仍可重排。保留原生倍率与能力解除规则。

死亡／缺席专属牌不再封存或禁用：由前排代打，攻击1费6→9并抽1；技能1费5→8挡并抽1；能力1费抽2→3并按原生能力牌流程离开牌堆。保留关键词、外部费用修正，不执行原正文、专有出牌限制或额外触发；费用、目标、描述同步临时变化，不改永久牌。生成、复制、自动打出及重放一致，归属者恢复后恢复原正文。

“1费”是原生改费流程的基础输入，不锁定最终费用。蛇眼的原生混乱抽牌改费、子弹时间的本回合免费，以及后续加减费仍按原生 LocalCostModifier 的施加顺序和期限处理。原X费牌代打时按普通1费参与该流程；复制保留原始X身份，角色恢复时自然还原。不追加一个会覆盖已有改费的临时费用副本。

斩杀收益遵循原生命令：最后一敌人的狂宴上限、贪婪之手金币、狩猎额外奖励正常保留；击倒在非清场击杀时回能，清场后 PlayerCmd.GainEnergy 按宿主 IsEnding 规则不再回能，不为它另造战后能量结算。

个人属性、防护、行动增益留在本人；纯共享资源、牌堆、持续场地能力挂真实玩家，来源死后仍沿原生期限。已施加给他人的状态不随来源死亡删除。共享Power用原生状态栏显示并提示来源，不显示第五人。真实角色决定本人攻击、减益、协同与格挡交接；共享抽弃、能量不按四人重复。

## 常驻飞碟与充能球

安缇娜使用常驻飞碟，平时悬停于头顶偏后；攻击按真实目标调整发射位置，再自然返回。独立射口随飞碟变换，与上方充能球锚点分开。基础／无专门演出攻击用原生小炮弹，扫荡射线用扫荡光束；编辑配置另可选大炮弹、超能光束、激光、祭司光束。原生场景中固定天空起点／固定时序的部分，只提取本功能需要的原生显示子树；不改原生怪物或其他角色。光束持续连接射口与目标，炮弹发射后独立飞行，命中跟随实际Damage入口，不额外发伤害、命中声或激发。本人、队列、血条不随飞碟移动，同牌的准备／攻击／生球不重新召唤飞碟。复用真实玩家唯一OrbQueue，存活安缇娜开战提供3空槽。

发射位按样式选择水平／高低角度，不强制位于角色身后高处。扫荡射线的显式起手在命令建立前读取已确定的群攻视觉目标，第二段Cast保持飞碟位置，随后按原生0.5秒投射物等待发射。原生扫荡贴图自带地面投影与扫转，局部显示适配保留原贴图/LUT，消除烘焙方向后指向实际目标。随机攻击仍由原生命令选择目标；选择前不向所有候选敌人假发射，真实Damage确定目标时显示即时接触段，不改变随机流或增加结算等待。

光束以目标为瞄准／接触点，不以怪物中心截断。超能保留原生2000单位及七点轮廓，激光采用原生3000单位，扫荡／祭司按原生素材范围继续延伸，远大目标另保证越过身体；炮弹仍在目标处命中。贯穿段在真实Damage时释放，不因加长射程而提前扫过敌人。单体超能优先上方“天基炮”构图；其他单体光束检查未受伤敌人的显示边界，优先保留原角度，无净空时改用上方／斜向射线，避免画面穿过无伤敌人。群攻允许穿过受伤目标。新发射接管时释放旧的附着光束尾段，不让旧射线随飞碟转场扫过其他目标。这些均为视觉规则，不增加穿透伤害。

上方发射位按敌人当前显示边界的顶部和飞碟自身下缘留空间，而非敌人中心加固定偏移；高个、浮空和体型缩放都参与计算。顶部空间不足时选择可见的斜上方侧翼，不将飞碟压进敌人头部或额外移动镜头。返航等光束可见消退／回缩完成，但该纯视觉尾段不阻塞下一张牌，新动作可直接接管。

原生大小球槽在飞碟上方弧形排列；扩容沿原生上限。集中取安缇娜，冰霜每次保护当前前排，等离子进入共享能量。安缇娜真正死亡清空现有球且不激发，飞碟退场，个人自动触发停用；球槽容量不因换位重置。没有存活安缇娜开战不赠3槽，外来卡／药水生成的球保持原生通用行为，在前排附近显示，不复原旧球。

卡框、标题横幅、插画边框按角色色着色，不染人物与文字；公共蓝灰#657F9A。仍用一个逻辑卡池和CardAssetProfile，稀有度纹理保留。

## 资源边界

基础打击素材仍来自默认攻击优先、单正伤害节点的已批准动作。2026-10-08 用户授权重新剪辑普通攻击、处决和普通受击：可重组姿态、移动可见命中时点、调整视觉位移，但不改变卡牌数值或增加结算次数，打击仍1费、单次6→9伤害。原始导入时间线保留作为素材依据，运行时使用角色自己的剪辑。

| 基础打击动作 | 同伴 | 原作依据 / 暂用原因 |
| --- | --- | --- |
| 攻击１ | 阿熊、爱丽丝、虎太郎、菊千代、小丑、扎帕、绮菈绮菈 | 默认动作，单正伤害节点 |
| 攻击２ | 安缇娜、梅蒂可 | 默认攻击１分别有6、4个正伤害节点；暂用单节点伤害技能 |
| 攻击３ | 珀尔诺 | 默认攻击１有2个正伤害节点；攻击３初始可用，且比攻击２短 |

依据外置当前原作表`30_技能数据.x`的`motionKey/level/type`与`33_モーション情報.x`的`Damage.Enable/Percent`。伤害技能与增益/治疗技能分别判定，不把名称含“攻击”的辅助动作当作普攻。以上是模组暂定适配，不改变专属攻击配置；后续细调另行确认。

`tools/Import-OriginalRoles.py` 只解析当前动作表及其明确引用，校验素材来源散列。
`tools/Prepare-Fmod.py` 新建本项目 Studio 工程，只保留宿主 Master/mixer关系，不引入历史自定义事件或bank。
`tools/Generate-Content.py` 仅生成选定原图的占位肖像；`tools/Sync-CatalogText.mjs` 同步三语，`Docs/card-metadata.json` 是实际宿主运行时导出。
原作图片、角色时间线、音频输入留在忽略提交的本地生成/制作目录，运行包仅包含选定资源和自己的bank。

所有通过 `SquadAudio` 播放的本模组音效与配音统一衰减20 dB，线性音量0.1；不修改原生音乐、环境音或音量设置。普通攻击不播放人物语音，处决在命中时播放该角色普通攻击的原作语音。每名角色的施放动画每场战斗首次释放时播放一次原作施放语音；技能和能力共用一次，攻击牌的Cast阶段不借此播放语音。受击／死亡语音覆盖动作配音，受击保留严格300ms重播限制。删除统一0.45秒截断：已选一次性动作音使用完整原生录音的自有FMOD事件，归属角色／房间；收招结束、胜利或下一姿态不会机械截断，退出统一释放。不恢复混有命中声的重复反馈，不改变原生音量，不增加WAV回退。

十人的打击、特殊攻击和施放均有拖牌预备段。借鉴忍者杀手龙卷拳的原生输入归属：`NMouseCardPlay.Start`／`NControllerCardPlay.Start`建立输入租约，`NCardPlay.Cleanup`区分提交和取消，原生队列撤销释放待执行姿态。预备由角色显示节点持有，不播放命中、发射或人物语音，不消费费用、随机流或能力，不提前近战插队；无论早放、准备中放出或蓄到待命，实际命令仍等待完整原生前摇。提交从当前帧接至释放点；收回短暂反向收势，可再次接管。正在结算的动作优先，纯视觉尾段允许续接，角色之间不互等。没有原生施放动画的卡牌不额外增加逻辑等待，未消费的预备在该次原生出牌结束时收回。退出、死亡及取消只释放本次显示状态，不新增存档字段。
