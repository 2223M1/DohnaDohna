# 小队设计编辑板

打开 [DohnaDohna-card-board.html](DohnaDohna-card-board.html) 即可离线编辑，无需安装依赖。固定8列；卡面168×235px，窗口宽度不超过1540px时154×216px，窄窗口可横向滚动。

## 编辑与拖动

- 名称、费用及合并正文直接在卡面编辑。数值用 `6→9`，费用用 `1→0`；不变值只写一次。非数字升级显示“升级后：…”或“升级后移除”。任意正文修改作为设计要求保存，不自动反解为游戏数值。
- 卡面费用旁可自主选择“攻击／技能／能力”；“详情”中也可修改。类别修改不会自动改费用、正文、近战标记或槽位，作为明确的设计改动保存并回交。
- “详情”独立选择攻击前摇（自动／普通0.15／重击0.20）和施放前摇（自动／0.25／0.40秒）。这些是命中／释放之前的时间，不是整段动画长度；不改变类型、近战标记或原生多段间隔。自动采用原型时序，旧板缺失字段等同自动。
- “飞碟发射”可选自动、小炮弹、大炮弹、扫荡光束、超能光束、激光、祭司光束。只在安缇娜实际执行时生效，不改变伤害、球结算或其他角色；自动保留扫荡射线，其余用小炮弹。字段为 `saucerShot`，旧板缺失等同 `Automatic`，回交后落实卡牌内部配置。
- “详情”可完整查看／编辑长文案、备注、归属、稀有度和卡牌类别，并核对原始基础／升级文案、模型 ID 与原型来源。原始字段不会被合并正文覆盖。
- 拖动 `⠿`：空槽移动，已有卡互换，其他卡不挤动。跨分区时，两张卡均按各自落点改变归属和稀有度；近战、卡牌类型、ID 与来源不变。不限制每组数量。
- “＋ 空槽”在对应分区末尾添加；选中空槽后可删除空槽或新建草案。“＋ 分区”可选择归属、稀有度并新增8槽。占用槽不可直接删除；卡牌删除在详情中确认。
- 搜索／过滤不改变布局。被隐藏的卡显示“已占用”，不能被拖入的卡覆盖。非卡牌条目放在各角色下方可折叠区，不接受卡牌拖入。角色身份被其他条目引用，不提供删除入口。
- “保存 HTML”下载／保存包含全部改动的独立HTML，重开即可继续。页面不联网、不改游戏、不依赖浏览器缓存。不要用浏览器“另存网页”代替板内保存。

## 旧板与回交

新版页面的“导入旧板”支持同基线旧HTML。只读取其JSON，不执行文件脚本；完整保留字段修改、新增／删除、排序、标记和备注，再按现有归属／稀有度建立槽位。导入是替换，不是合并；有未保存修改时会确认。请保存为新HTML并保留旧文件。

```powershell
node tools/card-board.mjs diff <回交HTML> [配套基线JSON]
```

差异包含 `added`、`removed`、`changed`，以及独立的 `layoutChanges`（新增／删除／调整分区、槽位和卡牌位置）。跨分区的 `role`、`rarity` 同时出现在字段差异中；自主修改的卡牌类别记录为 `type`（`Attack`／`Skill`／`Power`）。`designText` 是合并设计文案；`text`、`upgradedText` 保留原始／旧板编辑值。稳定ID与原型来源仍为只读身份，伪造变化会拒绝。

工具读取schema 1和2；新版输出schema 2。原基线JSON和`baselineHash`不因版式升级而变化。刷新模板而保留旧板修改可用：

动作档位差异单独记录为`attackWindup`（Automatic／Normal／Heavy）与`castWindup`（Automatic／Short／Long）；缺失与Automatic比较不产生伪改动。回交后映射到`SquadCardModel`对应内部配置，不增加跑局存档字段。

```powershell
node tools/card-board.mjs refresh [现有HTML] [输出HTML]
```

此命令先验证配套基线，再输出可审查补丁，不直接覆盖。`generate`则用于重新从运行时数据建立基线，不用于迁移玩家已编辑文件。

## 维护与测试

`tools/card-board.template.html`持有页面交互；`tools/card-board-model.mjs`持有文案合并、数据边界和初始布局，生成时内嵌到独立HTML，同时供差异工具与测试复用。无需运行时网络或外部脚本。

```powershell
node tools/Test-CardBoard.mjs <playwright模块路径>
node tools/verify-project.mjs
```

测试使用后台Chrome，截图及回交样本位于忽略提交的`build/authoring-proof/compact-board/`。它是浏览器协议鼠标／键盘验证，不代表物理桌面输入或游戏实机验收。
