# STS2 短动作、原地受击与紧凑处决（2026-10-08）

## 授权和实现

本次由 Codex 直接实施，不是再次交接 Claude。用户最新授权覆盖旧“处决完整原作”“原作后跳不可压缩”等限制。卡牌数值、默认素材来源、四实体归属、存档身份、药水/反伤/死亡结算保持不变。

- `MotionRecut` 对十人打击/特殊各选定起手、可见释放和收势姿态；删除长跑动、后空翻、弹丸漫游与大幅回跳。攻击仍只有一次 await 的原生命中。不是整条电影统一倍速。
- `RoleVisuals` 由角色持有纯视觉收势，在 `_Process` 推进。兼容且尚未撤回的同目标动作可以续接；更换目标/不兼容招式使用短起手与位置过渡。不同角色不等待彼此。没有全局动作字典、卡牌副本或无主后台 Task。
- 普通起手门槛采用原生0.15秒，快速0.075秒，即时不等待。纯视觉收势可以超过逻辑等待。处决保守清场判定不变，改为短动作配合受限镜头、压暗背景、旁人与其HUD淡出。
- 普通受击只选失衡姿态，移除素材内击退/回跳和额外 return，0.25秒恢复待机；300ms语音门槛、死亡覆盖保留。受击不取消尚待结算的攻击。
- 普通与处决命中均由原生 AttackCommand 产生一次图声。本版不播放攻击配音，也不播放原作目标命中爆炸/混合命中音；保留起手/发射音与受击/死亡配音。动作音随剪辑尾段停止，模组音频仍 −20dB，宿主音量不改。
- 删除不再有生产调用的原作长镜头、怪物身体控制、震动/闪色/线条分支。身体与地面影子/HUD层级分离，敌人自身受击动画保持原生。
- 原始导入动作与素材没有改写；珀尔诺特殊剪辑移除场外长吊具，只保留角色层及其影子；安缇娜飞碟/射口/光束保留共同构图。`CLAUDE.md` 和旧交接增加现行入口，技能正文仍真实指向 `.agents/skills/`。
- 逐帧回看纠正了两类剪辑问题：安缇娜原长光束在短收回期间残留，改为完整播放加快的充能/熄灭序列，在飞碟撤回前结束；小丑、绮菈绮菈、扎帕的球/手雷/拳头层先于身体，不能拿首个`IsShadow`层作身体位移基准。剪辑明确选择实际身体层，保留装备相对构图；小丑省去大幅腾空投球起手。

依据：本机0.111.0/0.107.1 `CreatureCmd.TriggerAnim`、`AttackCommand.Execute`、`CardModel.OnPlayWrapper`；本机 NinjaSlayer 的 `FastAttackAnimation`、`CombatActionTiming`、`NinjaSlayerRapidAnimationCoordinator`。只借鉴命中门槛与角色持有的可替换尾段，不移植其全套管理器。原作控制器、导入锚点及各角色源姿态联系表用于剪辑依据；改编时序不冒称原作事实。
