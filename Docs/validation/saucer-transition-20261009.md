# 飞碟发射、换位与自然收势 · 2026-10-09

本轮不改卡牌数值、小队规则、模型ID或存档字段。以下记录仅描述实际运行的证据；旧候选命令PASS不替代最终包视觉检查。

## 实现

- 飞碟拥有独立射口，跟随位置、姿态、缩放；不使用角色中心或球槽锚点。小／大炮弹、扫荡、超能、激光和祭司光束复用原生显示资源。发射位按样式和真实目标选择高低、距离，不再统一从身后高处发射。
- 扫荡贴图自带烘焙扫转和地面透视，直接旋转整个原生粒子会射偏。现在保留原贴图与LUT，在局部显示节点消除烘焙方向、接入释放时钟。群攻仍一次原生命令，各受伤者的原生命中特效在真实Damage时出现。
- 扫荡射线的显式Attack发生在AttackCommand建立前；读取已确定的群攻视觉目标，使飞碟提前赴发射位。后续Cast保持该状态，不再次召出、收回或重复起手。
- 炮弹发出后不随返航倒退；持续光束结束后返航。随机选择不提前消费RNG，不向所有候选目标假发射；实际目标确定后显示即时接触段。样式选择不会补播第二份命中声音。
- 纯换位不预备、不施法、不播施放语音，双方用原作跳跃素材。近战插队与首个前摇并行；逻辑队列、光环、换位收益仅结算一次。布局仍是唯一真实站位/HUD写入者。
- 连续收招帧不再统一抽稀、强压短尾段；普通受击保留失衡与恢复，移除击退/跳回。视觉尾段由角色持有，后续出牌可接管，不追加逻辑等待。
- 近战处决按原作Range、身体锚点和目标位移计算接近距离，在玩家侧展示；不是按图片包围盒贴住敌人。允许原作跳回，独立于镜头回收和胜利结算。敌人不受额外形变或位移。
- 黑底与原作配色/闪光分层，透明关键帧只结束上层颜色，不提前清掉黑底。退出树不再重复RemoveChild，也不在退场时启动新跳回。
- 已发出的一次性动作音自然播完，不再统一截至0.45秒或随姿态结束停声。模组音量仍−20dB；普通攻击无配音、处决普通攻击语音、每人每战首次施放语音及受击/死亡优先规则保持。
- 编辑板增加独立`saucerShot`，旧数据默认Automatic。安全差异提取只读数据；基线未重建，现板既有内容/布局不变。

按工程modding／code-quality技能约定，伤害、多段、附效及死亡继续等待原生命令；只在角色/单次发射/处决房间内持有视觉状态，没有新增全局兼容层。

## 贯穿、单体避让与敌人高度的追加修正

- 将瞄准、接触与射程分开，光束在真实Damage时释放贯穿段，原生命中特效仍落在受伤者。保留超能七点轮廓；群攻范围延伸超过最远目标，不只超过平均点。炮弹不变，不增加穿透伤害。
