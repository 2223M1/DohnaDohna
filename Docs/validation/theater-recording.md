# 四人真实打牌剧场

入口为`tools/Invoke-IsolatedBoot.ps1 -CommandScenario Theater`。不另建演出版本的模组；只在隔离SmokeDriver中准备阿熊、爱丽丝、安缇娜、菊千代及战斗夹具。

剧场包括真实史莱姆招式、拖牌准备/取消、公共牌、施放/充能球、后排远程、近战插队、换位、连续攻击与可靠清场处决。卡牌通过原生手牌输入/行动队列打出，消耗费用；伤害、增益、抽牌与胜利来自生产代码。初始敌人HP和额外能量为镜头展示夹具，开录后不改敌人HP制造死亡。它不是自然生成牌序的整局录像，也不是物理鼠标操作。

`TheaterRecording`借鉴忍杀当前生产剧场：实际viewport在绘制后异步GPU读回，按请求QPC记录；编码60fps，迟帧补前帧以保存原始墙钟，不加速游戏。队列超过编码能力明确报错，不默默跳过时间。

`AudioCapture`仅录制该隔离游戏进程，WASAPI数据包QPC与视频使用共同系统时钟。`Export-Theater.py`再通过该次真实FMOD输出匹配源文件，求本次的播放延迟并合成；不使用另一次测试的声音。至少三个相隔足够远的高置信锚点，每个锚点须由两个不重叠100ms片段确认；合成AAC再次验证最大40ms误差。报告单独列出未匹配事件、实际捕帧率、重复帧和音频时钟漂移，不把文件存在或函数调用当成听得到/同步通过。

执行方法与最新Fast影片入口见[当前验证记录](fast-presentation-20261009.md)，上一轮录像留在[历史记录](reaction-continuity-20261009.md)。原始录像、音频和时间戳保留在忽略提交的`build/`中；驱动、ffmpeg和录音程序均不进入游戏模组包。后台桌面不切换用户前台；隔离BGM/环境音静音，其他应用声音不录入。
