# 动作档位、预备、非阻塞收势与四人剧场（2026-10-09）

本轮改变演出，不改卡牌数值、小队规则或存档模型身份。十人共享三个出牌 cue（打击、特殊攻击、施放），不是十人共用同一条动画。

## 实现

- `MotionRecut` 从原作选定动作中分别选姿态、重定时、压缩位移。打击/特殊提供0.15/0.20秒，施放提供0.25/0.40秒。自动档保留原型特殊等待；角色模板在当前出牌作用域读取原型时序，显式动画等待仍保留。原生投射物、多段间隔和附加效果不被替代。
- 攻击回到原生`AttackCommand.Execute`，不再用整段自制动画包住攻击循环。角色持有`_Process`视觉尾段，真正收招、返回待机和飞碟返航不加入逻辑等待。每张牌仍完整等待自己的前摇；兼容续接、不兼容短过渡和不同角色独立行动分开处理。
- `NMouseCardPlay`/`NControllerCardPlay`原生开始、提交、取消与队列撤销提供预备输入边界。角色持有准备姿态，提交从当前帧接入、取消短回收；不提前发射、播语音、扣费、换位、消费能力或随机流。未触发原生身体动画的牌也会在出牌完成时回收预备，不额外加施放等待。
- `RoleFinisher`为房间所有的视觉演出，采用忍杀生产B档参考。近战身体接近实际敌人边界，远程命中聚焦；遮罩使用对应原作配色。原生震动设置、镜头边界和HUD共同绘制保留。`RoleDoomHold`仅延缓节点回收、显示hurt定格，原生死亡状态和奖励照常，不加Doom能力、不写假活血量、不变形怪物。
- 普通攻击无人物配音；处决命中播放原作普通攻击语音。技能/能力共用施放动画，每角色每战首次释放一次语音，攻击中的Cast阶段不借此播放。75个短动作声音使用自己的FMOD事件，最多0.45秒、最多60ms尾淡出；不加速人物语音。模组统一−20dB，原生音量不变。
- 编辑板保留既有布局、修改与基线，增加独立攻击/施放档位；缺失字段等于自动。回交工具只解析数据，不执行HTML脚本。

原作姿态是素材依据，当前重剪是STS2适配，不宣称时间线完全复刻原作。借鉴忍杀的所有权、镜头和录制方式，没有复制其角色机制、输入系统或全局协调平台。

### 保留的失败与修正证据

- 早期Preparation夹具漏设原生`KeyboardMode`，Space仅聚焦不提交；`123216-995`、`123359-394`记录保留，不能列为通过。修正夹具后原生输入通过。
- `audio-flow-20261009-125301-494`的Pacing失败：墙钟渲染波动时，两个同样0.15秒的门槛分别用了5帧和10帧。原断言误把固定MovieWriter帧数判据用于可变步长；改成固定录像比较帧数，墙钟模式核对真实计时与所测帧边界。没有修改生产动作速度或降低音频匹配门槛。
- 墙钟重跑还发现原生Godot计时器的当前帧计入边界：Fast请求0.1000秒，实际0.0974秒，少于一帧。判据按实测最长帧允许当前帧量化，不使用错误的2ms绝对下界；保留该失败日志`build/motion-final-pacing-retry.log`。
- `audio-flow-20261009-130807-908`中Instant没有跨帧等待，但安缇娜特效同步准备耗时43ms，触发了错误的25ms“动画等待”上限。Instant改为断言零跨帧，CPU耗时仍记录，不将同步渲染成本伪装成等待或宣称零耗时。
- `audio-flow-20261009-131602-511`中珀尔诺0.20秒重击观察耗时0.7962秒，原判据失败。随后只增加测试诊断与失败时保存记录，没有放宽判据或改变生产速度。定向18样本和全员180样本复测通过；全员重测该项为0.2153秒（准备0.00086秒、原生等待0.19821秒，剩余约一帧为测试观察延迟）。此前尖峰未复现，也未证明是外部负载导致，保留为未定位的单次耗时异常，不声称已修复其根因。
- 最终墙钟矩阵另记录一次虎太郎首次施放的同步准备约92ms，发生在144ms帧附近；该项总观察0.2106秒，体现原生计时器计入当前帧的边界，不是额外后摇等待。其他179项同步准备不超过8.1ms，Instant均零跨帧。`pacing.json`中的`contactSeconds`包含测试下一帧才观察完成的延迟，不能把它当成生产命中计算耗时；详细engine/wall帧间隔与原生配对样本一并保留。
- 早期Doom在原生死亡轨道启动时被覆盖，已在死亡视觉边界恢复hurt定格、释放后还原死亡轨道；震动移交改为有效临时目标，避免原生伤害时无目标警告。旧`121108-879`不作为最终处决视觉通过依据。
- `124843-718`的逐帧复核还发现准备姿态的美术问题：绮菈绮菈特殊动作停在已挥出的粉色轨迹，小丑准备中途闪过原作黑剪影。最终剪辑改为投掷前的准备帧，去掉准备段的黑剪影；结算、实际攻击与声音不变。该两处以补录为准。
- 剧场首次`audio-flow-20261009-133244-917`失败：仅传`forward_plus`仍使用Windows默认D3D12，在异步GPU读回时报设备丢失。补上忍杀剧场实际使用的`--rendering-driver vulkan`，只改变隔离录制的后端，不修改日常游戏渲染设置。首段不作为有效录像。
